## RÈGLES D'ALERTE (à vérifier chaque lundi)

🔴 **ALERTE CRITIQUE** — Agir immédiatement si :
- Churn > 10% sur une semaine
- 0 démo réalisée depuis 3 jours
- < 3 nouveaux prospects/jour
- 1 client important menace de partir

🟡 **ALERTE ATTENTION** — Revoir la stratégie si :
- Taux conversion démo → pilote < 50%
- Délai moyen prospect → client > 15 jours
- NPS < 7 sur 3 clients consécutifs
- Parrainage : 0 référence en 2 semaines

🟢 **SIGNAUX POSITIFS** — Amplifier si :
- Taux conversion pilote → payant > 80%
- Un segment sur-performe (ex: PME > taxi)
- Un quartier génère 3× plus de leads
- Un commercial outscore les autres → dupliquer sa méthode
