## Définitions minimales

- **Auth success rate** : connexions réussies / tentatives de connexion.
- **OTP success rate** : OTP validés / OTP émis.
- **QR success rate** : scans validés / scans tentés.
- **Violations RLS** : incidents ou tests qui démontrent un accès inter-tenant.
- **CORS wildcard count** : nombre d'endpoints critiques avec `Access-Control-Allow-Origin: *`.
